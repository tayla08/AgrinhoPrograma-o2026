O AgroClima Paraná é uma aplicação web desenvolvida para auxiliar produtores rurais no monitoramento climático e no planejamento da irrigação. A plataforma consulta dados meteorológicos em tempo real por meio da API Open-Meteo e apresenta informações sobre chuva e temperatura para diversas cidades do estado do Paraná.

Com base na previsão de precipitação e na quantidade de hectares informada pelo usuário, o sistema calcula a quantidade de água recomendada para irrigação e estima a economia de recursos hídricos que pode ser obtida. Além disso, o projeto conta com um mapa interativo que permite visualizar rapidamente as condições climáticas das cidades monitoradas, utilizando diferentes cores para representar a intensidade da chuva prevista.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, juntamente com a biblioteca Leaflet para a exibição do mapa e OpenStreetMap para os dados cartográficos. Seu principal objetivo é incentivar práticas agrícolas mais eficientes e sustentáveis por meio do uso inteligente de informações climáticas.
